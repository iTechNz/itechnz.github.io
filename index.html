How to Deploy this Landing Page

Your GitHub Pages URL Structure:
  • Root Portfolio: https://itechnz.github.io/
  • Project 1: https://itechnz.github.io/First-Order-Response/
  • Project 2: https://itechnz.github.io/Second-order-response/
  • Project 3: https://itechnz.github.io/Single-Harmonic-Motion-Simulator/index.html
  • Project 4: https://itechnz.github.io/Virtual-Strain-Gauge-Simulator/

Quick Setup Steps (3 minutes):

  1. Create a new public repository on GitHub named exactly itechnz.github.io.
  2. Upload this file as index.html in that repository.
  3. In the repository, open Settings → Pages. Ensure Source is set to "Deploy from a branch" with branch main / root folder. (Note: do not click "Publish packages", which is for package managers like npm/Maven).
  4. GitHub will deploy your landing page directly to https://itechnz.github.io/, linking seamlessly to all 4 simulators!
